# FreeRange-Exam-Suite
FreeRange Exam Suite is a free, portable application developed in Python for test and exam management and simulation. Lightweight, clean, and makes no changes to the system registry. Also available on the Microsoft Store!

**FreeRange Exam Suite** is a lightweight, portable application developed in Python for test and exam management and simulation. 

Designed with simplicity and privacy in mind, it operates entirely locally without modifying the system registry or leaving unnecessary files behind.

## Features

* **Portable & Clean:** Runs seamlessly without requiring complex installations or modifying system configurations.
* **Exam Simulation:** Designed to help users manage, create, and practice tests efficiently.
* **Privacy Focused:** Does not collect or transmit personal user data.
